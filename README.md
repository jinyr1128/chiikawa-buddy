# 🐹 치이카와 매니저

바탕화면 구석에 치이카와 친구들이 살면서, **AI(Claude Code·Codex·Hermes)가 일하는 모습을 캐릭터 대사로 실시간 중계**하고 **메일·Slack·캘린더·노션·GitHub 알림**을 한곳에 모아 주는 맥 데스크톱 매니저예요.

<img src="docs/images/hero.png" alt="왼쪽: 치이카와가 「login.ts 읽는 중」이라고 말하며 일하는 모습. 가운데: 우사기가 노란 말풍선으로 일하는 모습. 오른쪽: 하치와레 위로 Claude 완료·메일·Slack 알림 카드가 쌓인 모습">

> 비상업 팬 프로젝트예요. 무료이고 돈을 받지 않아요. 치이카와 캐릭터의 권리는 원작자(나가노)와 권리사에 있어요. 개인적으로 즐기는 용도로만 써 주세요. 권리자가 요청하면 바로 내릴게요.
> [시사 비서(shisa-agent)](https://github.com/cheo0y/shisa-agent)(MIT)를 바탕으로 만들었어요.

## 🤖 처음이든 쓰던 분이든, AI에게 이 문장만 보내세요

내 컴퓨터의 파일·터미널을 사용할 수 있는 AI에게 아래 내용을 그대로 붙여 넣으세요.

```text
https://github.com/jinyr1128/chiikawa-manager
이거 내 컴퓨터에 설치해줘. 최신 AGENTS.md를 읽고 진행해줘.
이미 설치되어 있으면 기존 계정 연결·설정·캐릭터·기록을 그대로 유지하고 최신 버전으로 업데이트해줘.
설치 후 실행과 버전, 연결 상태까지 확인해줘.
```

**처음 쓰는 분은 새로 설치, 이미 쓰는 분은 앱만 업데이트**합니다. 사용자가 설치 파일을 직접 골라 받을 필요는 없습니다. 초기 로그인이나 운영체제 승인처럼 직접 해야 하는 단계는 AI가 안내합니다. 개인용 수정 앱은 공개판으로 덮어쓰지 않고 개인용 소스를 유지합니다.

아래 직접 다운로드 방법은 AI 없이 설치할 때만 사용하세요.

## 다운로드 · 업데이트 · 화면 설정

### AI 없이 직접 설치하는 분

- **Mac M1 이상:** [최신 Mac 다운로드](https://github.com/jinyr1128/chiikawa-manager/releases/latest)에서 `chiikawa-manager-arm64.zip`을 받습니다. 압축을 풀고 앱을 ‘응용 프로그램’으로 옮겨 실행합니다. AI 작업 연동까지 자동으로 설정하려면 아래 AI 설치 방법을 이용하세요.
- **Windows 10·11:** [Windows 릴리스](https://github.com/jinyr1128/chiikawa-manager/releases?q=windows&expanded=true)에서 가장 최신 버전의 `Setup.exe`를 받아 실행합니다. Mac zip은 Windows에서 실행되지 않습니다.
- 실행 후 메뉴 막대/알림 영역의 캐릭터 아이콘 → **홈 → 연결 관리**에서 필요한 서비스만 연결합니다.

### 이미 설치한 분 — 연결을 유지하고 업데이트

1. 기존 치이카와 매니저를 **종료**합니다. 연결 해제나 데이터 삭제는 하지 않습니다.
2. Mac은 새 zip을 풀어 **기존 앱과 같은 위치에 덮어쓰기(대치)**합니다. Windows는 새 `Setup.exe`를 실행합니다. 휴대용 버전은 새 zip을 풀어 실행합니다.
3. 앱을 다시 실행합니다. 같은 컴퓨터·같은 OS 사용자 계정에서는 **연결된 계정, 설정, 캐릭터, 기록이 유지**됩니다. 서비스 자체의 로그인 만료·권한 철회 시에는 재인증이 필요할 수 있습니다.

Mac에서 저장소로 설치했다면 저장소 폴더에서 `./ops/update.sh`를 실행해도 됩니다. 이 방법은 앱만 바꾸며 초기 설정·캐릭터·후크를 다시 설치하지 않습니다. 개인용으로 수정한 앱은 공개 설치 파일로 덮어쓰지 말고 개인용 코드를 업데이트하세요.

### 캐릭터 크기 · 말풍선 · 반투명 알림

**홈 오른쪽 위 ⚙ 설정 → 이 앱**에서 바꿉니다.

| 설정/버튼 | 동작 |
|---|---|
| 캐릭터 크기 | 50~150%, 캐릭터 이미지 크기 조절 |
| 안내 말풍선 크기 | 50~150%, 안내 글·알림 카드 표시 크기 조절 |
| 말풍선 가리기 ↔ 말풍선 보이기 | 대화·작업 상태·입력창을 숨기거나 다시 표시 |
| 알림 가리기 ↔ 알림 보이기 | 위쪽 반투명 알림 카드만 숨기거나 다시 표시 |
| 크기 기본값으로 | 두 크기를 100%로 복원 |

캐릭터 옆의 두 버튼은 숨긴 뒤에도 남아 있어 바로 다시 켤 수 있습니다. 말풍선과 알림은 서로 독립적으로 표시합니다. 알림을 가려도 수신은 계속되고 홈의 알림함에서 볼 수 있습니다. 설정은 다음 실행에도 유지됩니다. 설정의 **업데이트 다운로드 · 방법 보기**에서 새 버전을 받을 수 있습니다.

## 🤖 설치는 AI에게 맡기세요

**애플 실리콘 맥(M1 이후)** 이나 **윈도우 10·11** PC에서, **내 컴퓨터의 파일과 터미널을 다룰 수 있는 AI**(Claude Code·Codex 등)에게 이렇게만 말하면 돼요.

> **이 저장소 주소(`https://github.com/…`)를 붙이고 「이거 내 컴퓨터에 설치해줘. AGENTS.md 대로 해줘」**

- 웹 채팅창(ChatGPT 웹·Claude 웹)에 주소만 붙여 넣으면 설치할 수 없어요.
- 공개 저장소라 **GitHub 로그인이 필요 없어요.** AI가 [`AGENTS.md`](AGENTS.md)를 읽고 받기 → 설치 → 확인까지 해요.
- 사람이 직접 할 일은 두 가지예요. macOS가 「캘린더 접근」을 물으면 **[전체 접근 허용]**을 눌러요. 그리고 앱의 **「연결 관리」**에서 내 계정을 연결해요(열쇠·비밀번호는 AI에게 알려 주지 말고 직접 붙여 넣어요).

<details>
<summary>윈도우에서 직접 설치(PowerShell)</summary>

```powershell
git clone <이 저장소 주소>.git chiikawa-manager
cd chiikawa-manager
powershell -ExecutionPolicy Bypass -File ops\setup-win.ps1
```

- 최신 윈도우 릴리스(`v<버전>-windows`)에서 설치 파일을 받아 검증하고, 관리자 권한 없이 `%LOCALAPPDATA%\ChiikawaManager`에 설치해요. 바탕 화면·시작 메뉴 바로 가기와 로그인할 때 자동 실행이 생겨요.
- 처음 실행할 때 파란 「Windows의 PC 보호」 창이 뜨면 「추가 정보」 → 「실행」을 눌러요.
- 캐릭터 얼굴 아이콘은 작업 표시줄 오른쪽 알림 영역(시계 옆, 안 보이면 `^`)에 있어요. 캘린더는 iCal 비공개 주소로 연결해요(맥 캘린더 기능은 맥 전용). 자세한 건 [windows/README.md](windows/README.md).
- **업데이트**: 저장소 폴더에서 `git pull` 후 같은 명령을 다시 실행해요.

</details>

<details>
<summary>맥에서 직접 설치(터미널)</summary>

```bash
git clone <이 저장소 주소>.git chiikawa-manager
cd chiikawa-manager
./ops/setup-mac.sh
```

- 이 저장소의 최신 릴리스에서 앱(zip)과, 있으면 캐릭터 묶음을 받아 SHA-256으로 검증해요.
- `/Applications/치이카와 매니저.app`에 넣고, 캐릭터는 `~/.cy-agent`에 넣어요.
- Claude Code가 있으면 Claude Code 연동을, Hermes가 있으면 Hermes 연동을 켜요. Codex는 설정이 필요 없어요.
- 옵션: `--build`(소스로 직접 만들기, Node.js 24+ 필요) · `--no-hooks`(AI 연동 안 켜기) · `--tag v0.5.0`(그 버전으로 설치)
- **업데이트**: 저장소 폴더에서 `./ops/update.sh`. 설정과 캐릭터는 그대로 남아요.
- **지우기**: 앱을 끄고 `/Applications/치이카와 매니저.app`을 지워요. 데이터는 `~/.cy-agent`에 있고, Claude 연동은 `node ops/claude-hooks.mjs off`로 꺼요.

</details>

## 할 수 있는 일

**🛠 AI 작업 실시간 표시**
- Claude Code(터미널·데스크톱 Code 탭·IDE), Codex(CLI·ChatGPT 앱), Hermes Agent가 일하면 캐릭터가 작업 움짤을 틀고, 「login.ts 읽는 중」처럼 지금 하는 일을 **캐릭터 말투로** 말해요.
- 일이 끝나거나, 내 확인이 필요하거나, 토큰 한도에 걸리면 바로 알려 줘요. 한도에 걸렸을 때는 언제 다시 쓸 수 있는지도 알려 줘요.
- 홈 화면의 **AI 사용량**에서 Claude·Codex 한도를 몇 % 썼는지(5시간·주간), 언제 초기화되는지, 오늘 쓴 토큰을 봐요. 터미널 Claude Code 아래 상태 줄에도 `🐹 5시간 42% · 주간 23%`처럼 나와요.

**📬 알림 모으기**
- 메일(여러 계정)·Slack(DM·멘션)·캘린더(회의 30분·10분 전)·노션(마감·댓글)·GitHub(리뷰 요청·멘션)을 캐릭터 위 카드로 보여 줘요. 읽기 전에는 사라지지 않아요.
- 카드에서 바로 **열기·읽음**을 누를 수 있어요. Slack 답장과 승인된 PR 머지도 카드에서 해요.

**💬 캐릭터와 놀기**
- 캐릭터를 **두 번 클릭**하면 말을 걸 수 있어요. AI를 연결했다면 입력창이 뜨고, 입력창 왼쪽 **＋** 에 「응원해 줘」「춤춰 줘」「다음 일정은요?」 같은 칩이 있어요. AI가 없으면 칩이 바로 떠요.
- 패널의 「채팅」에서는 길게 대화하고 파일도 붙일 수 있어요.

**📅 하루 챙기기**
- 홈, 오늘 할 일, 할 일, 프로젝트, 캘린더(주·월·일), 집중하기(집중 시간 기록) 탭이 있어요.
- 출근 인사, 점심 알림, 퇴근 10분 전 인사와 날씨 알림을 해요(근무 시간은 설정에서 바꿔요).
- 자리를 30분 넘게 비웠다 돌아오면, 그리고 퇴근 전에 **브리핑**으로 밀린 메일·Slack·AI 작업을 정리해 줘요.
- **방해 금지**(1시간 등)와 **회의 중 자동으로 조용히** 모드가 있어요. 머지 승인과 오류만 예외로 보여요.

## 캐릭터

기본 캐릭터 8명이 들어 있어요. 말투와 **말풍선 대표 색**이 캐릭터마다 달라요.

| 캐릭터 | 말투 | 대표 색 |
|---|---|---|
| 치이카와 | 「싫어」「에에에」 같은 소리 뒤 괄호에 뜻 — `에헤헤 (오늘도 같이 해 보자!)` | 흰색 |
| 우사기 | 외침 뒤 괄호에 뜻 — `우라! (오늘 할 일 3개 남았어)` | 개나리 노랑 |
| 하치와레 | 밝은 반말 | 하늘색 |
| 시사 | 제주 사투리 존댓말 — `고맙수다!` | 주황색 |
| 쿠리만쥬 | 「캬」 뒤 괄호에 뜻 | 초록색 |
| 랏코 | 차분하고 듬직한 말투 | 회색 |
| 카니 | 소리 뒤 괄호에 뜻 — `헤헤헤... (같이 힘내 보자!)` | 분홍색 |
| 모몽가 | 떼쓰는 말투 — `칭찬하란 말이야아아!!!` | 연보라 |

- 일하는 동안 나오는 **작업 움짤은 캐릭터마다 3개 이상**이고 10초마다 바뀌어요.
- **캐릭터 만들기**: 메뉴 막대 → 설정… → 캐릭터 → 「＋ 새 캐릭터」에서 움짤(gif·png·webm)을 넣어 내 캐릭터를 만들어요. 움짤 배경 지우기·묶음 내보내기·들여오기 도구는 [`ops/character-pack`](ops/character-pack/README.md)에 있어요.
- 둘이 주고받는 캐릭터도 만들 수 있어요. 대사를 `모몽가: … / 카니: …`처럼 쓰면 한 줄에 한 사람씩, 각자 색으로 보여요.

| 캘린더 | 회의 30·10분 전 알림, 회의 중엔 조용히 | 맥 「캘린더」 앱에 넣은 계정(구글·네이버 CalDAV·iCloud) 또는 iCal 비공개 주소 |
| 노션 | 내 할 일 마감, 수정·새 댓글 알림 | 노션 내부 통합 시크릿(`ntn_`) + 알림받을 페이지에 통합 연결(회사 워크스페이스는 관리자 허용이 필요할 수 있어요) |
| GitHub | 리뷰 요청·멘션 알림, 승인된 PR 머지, 댓글 답장 | `gh` 로그인 |

캐릭터와 자유롭게 대화하거나 브리핑을 요약하려면 AI(Claude Code·Codex 또는 API 키)를 「AI 설정」에서 골라요. AI가 없어도 알림·할 일·칩·집중하기는 다 돼요.

## 개인정보와 안전

- 메일·메시지·할 일·대화·열쇠는 모두 **이 맥의 `~/.cy-agent/` 안에만** 있어요. 저장소나 릴리스에는 들어가지 않아요.
- 열쇠·비밀번호는 `config.json`에 저장되고, 나만 읽을 수 있는 권한(600)으로 만들어요. 로그에는 남기지 않아요.
- 로컬 서버는 `127.0.0.1`에서만 열리고, 전용 헤더가 없는 쓰기 요청은 거절해요.
- AI를 고르면 브리핑과 대화에 필요한 글이 그 AI 회사로 가요. 날씨 지역을 고르면 Open-Meteo에 위치만 보내요. 새 버전 확인으로 하루 한 번 GitHub에 버전 번호를 물어요(설정에서 끌 수 있어요).

### 설명보기와 노션 자동 업무기록

앱 왼쪽 **설명보기** 탭에서 기능 소개, 처음 설정 순서, 계정 연결 방법과 문제 해결 안내를 볼 수 있습니다.

노션 자동 업무기록은 **기본 꺼짐**입니다. 배포 파일에는 개발자의 노션 계정이나 저장 페이지가 포함되지 않습니다. 각 사용자가 다음 설정을 마쳐야 작동합니다.

1. **연결 관리 → 노션**에서 본인의 내부 통합을 연결합니다. 통합 시크릿은 본인이 앱에 직접 입력합니다.
2. 통합에 **콘텐츠 읽기·추가** 권한을 부여하고, 저장할 일반 노션 페이지에서 **··· → 연결**로 해당 통합을 추가합니다.
3. 노션 카드의 **17시 자동 업무기록**에 상위 페이지 주소를 넣고 **이 페이지에 자동 기록 켜기**를 누릅니다. 데이터베이스 직접 저장은 지원하지 않습니다.
4. 월~금 **17:00, 한국 시간**에 날짜별 하위 페이지를 생성합니다. **오늘 기록 지금 실행**으로 시험하고 **상태 새로고침**에서 결과를 확인할 수 있습니다.

컴퓨터와 앱이 켜져 있고 인터넷과 선택한 AI의 로그인이 필요합니다. 당일 17시 이후 앱을 켜면 실행하지만 전날 기록을 자동 소급하지는 않습니다. 근거가 없는 날은 건너뜁니다. 정리 범위는 치이카와에 기록된 당일 할 일 변경과 작업 제목·실행 상태이며, 컴퓨터 전체 활동이나 모든 대화를 수집하는 기능은 아닙니다. 같은 날짜의 기존 일지나 사용자가 작성한 내용은 덮어쓰지 않습니다. 저장 결과가 불확실하면 중복 생성을 막고 상태에 안내합니다. 계정을 바꾸면 저장 위치를 다시 설정해야 합니다. 저장 페이지의 공유 범위는 사용자가 결정합니다.

노션 저장은 [공식 페이지 생성 API](https://developers.notion.com/reference/post-page)를 사용합니다. 실제 계정 연결과 권한이 없으면 저장되지 않습니다.

### 날씨 기본 지역과 화면 설정

날씨 지역을 설정하지 않은 경우 컴퓨터 시간대의 **대표 도시**를 기본값으로 사용합니다(예: `Asia/Seoul` → 서울). 실제 현재 위치를 측정하는 기능이 아니며 GPS·IP 위치 추적은 하지 않습니다. 지원하지 않는 시간대에서는 지역을 검색해 선택하세요. **설정 → 날씨 지역·알림**에서 지역 변경, 컴퓨터 시간대 기준으로 설정, 끄기가 가능합니다. 기존에 직접 지정하거나 꺼 둔 설정은 유지합니다. [Open-Meteo](https://open-meteo.com/) 예보를 사용하며 인터넷이 필요합니다.

**설정 → 이 앱**에서 캐릭터·말풍선 크기를 각각 50~150%로 조절하고, 말풍선·반투명 알림 표시를 따로 켜고 끌 수 있습니다. ‘크기 기본값으로’는 두 크기를 100%로 복원합니다.


### 개인 노션에 채팅으로 작업 부탁하기

본인의 노션 통합을 연결하고 사용할 상위 페이지에 접근을 허용하면, 채팅에서 페이지 검색·읽기·요약과 새 하위 페이지 생성, 본문 추가, 제목 변경, 텍스트 블록 수정을 요청할 수 있습니다. 통합 권한은 **콘텐츠 읽기·추가·업데이트**가 필요합니다. 자동 업무기록 설정과 별개로 이용할 수 있습니다.

예: “노션에서 프로젝트 자료 찾아줘”, “이 페이지 요약해줘”, “이 페이지 아래에 회의록 만들어줘”, “이 문단을 간단히 고쳐줘”. Claude Code뿐 아니라 Codex 등 구조화 응답을 지원하는 채팅 AI도 노션 검색·읽기 요청을 이용합니다.

쓰기 요청은 대상·기존 내용·작성 내용을 확인 카드로 보여 주며 **실행**을 눌러야 저장합니다. 대상 내용이나 연결 계정이 바뀌면 새 요청이 필요합니다. 한 요청당 최대 3개 작업, 본문 8,000자, 문단 수정 1,800자까지 지원합니다. 문단 수정은 해당 문단의 글자 서식·링크를 일반 텍스트로 바꿉니다. 페이지 전체 삭제·이동, 데이터베이스 구조 편집은 지원하지 않습니다. 저장 중 통신 오류가 나면 자동 재시도하지 않으니 노션에서 결과를 확인하세요.

바탕화면 캐릭터 위의 **채팅하기** 버튼을 누르면 설정 창 없이 입력할 수 있습니다. 입력창은 말풍선을 가려도 사용할 수 있으며 Esc로 닫습니다. 날씨 지역은 검색 결과를 선택하면 저장됩니다.

## 처음 연결하는 순서

앱의 **설명보기** 또는 [연결·설정 안내](docs/연결-설정.md)를 따라 AI → 옵시디언/노션 → 캘린더/Slack → Teams → 그룹웨어 순서로 필요한 기능만 연결하세요. 자동 업무정리·Slack 상태 변경·그룹웨어 연결은 기본 꺼짐이며 각 사용자가 본인 계정과 폴더를 설정해야 합니다. Teams는 회사·학교 계정의 최근 채팅·일정 읽기를 지원하며 관리자 승인이 필요할 수 있습니다.
