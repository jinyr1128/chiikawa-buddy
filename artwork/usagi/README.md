# 우사기 그림 원본과 출처

이 폴더의 PNG 네 장은 2026-10-16에 **내장 image_gen 도구**로 제작한 치이카와 우사기 팬 아트다. 기본 그림과 집중 그림은 유지한다. 춤은 영화 공식 랩 영상의 선글라스 모습, 응원·알림은 치타라 간식을 든 날개짓·점프로 바꿨다. 공식 제작물이 아니며, 원작 캐릭터의 권리는 © Nagano / chiikawa committee에 있다. 코드의 MIT 라이선스에 포함되지 않는다. 팬 아트를 생성했다는 사실은 권리자의 이용·재배포 허락을 뜻하지 않는다. 기존 저장소의 캐릭터 자산 사용 조건도 함께 확인한다.

기본 외형은 [애니메이션 공식 사이트의 우사기 이미지](https://www.anime-chiikawa.jp/images/img_chara_03.png)를 참고했다. 재작업은 상태별로 실제 라이선스 아트·제조사 상품의 자세를 직접 입력했다. [레퍼런스 검토](reference-review.md)와 [역할·URL·유지한 그림 해시](references.json)를 함께 보관한다. 참고 원본은 앱 번들에 복사하지 않았다.

| 파일 | 제작 방식 | 앱에서 사용하는 곳 |
|---|---|---|
| `idle.png` | 처음 만든 기본 그림을 그대로 유지 | 대기 `eyes_open.png` |
| `study.png` | 키탄클럽 공식 상품의 파란 필기구·종이 자세를 idle 그림체로 각색 | 집중·작업 `study.png` |
| `cheetara-sheet.png` | 원작·애니메이션의 치타라 날개짓을 네 자세로 제작. 중앙만 연결된 세 갈래 간식은 양끝을 펼침 | 응원·알림 포스터, 8fps 자세 반복과 48px 점프 |
| `rap-sheet.png` | 영화 공식 랩 영상의 선글라스·금색 목걸이·마이크를 2×2 네 자세로 제작 | 춤 포스터와 4fps 자세 반복. 머리 옆 돌출 부분과 손 정리 |

임의로 각색했던 감은 눈 그림은 제거했다. 우사기는 깜빡임과 연결 끊김 상태에서도 열린 눈의 기본 그림을 유지한다. 이는 앱의 표현 선택이며, 원작에서 눈을 감는 장면이 없다는 뜻은 아니다.

입력·편집 지시 전문은 [prompts.json](prompts.json)에 있다. 각 입력의 역할을 구분했고, 재작업에서는 기존 생성 그림만 연쇄 참조하지 않았다. 도구의 결과는 비결정적이므로 같은 프롬프트로 완전히 같은 그림을 얻는다고 보장하지 않는다. 이 폴더 원본으로 앱 자산을 준비하는 과정은 아래와 같다.

```sh
# 저장소 루트, Node.js 24+ 및 ffmpeg(libvpx-vp9) 필요
node desktop/scripts/prepare-usagi.mjs
node desktop/scripts/sync-character-lines.mjs --check
```

준비 스크립트는 PNG를 512 정사각형의 투명 여백 안에 맞추고, 집중은 기존 이동 모션을 유지하고, 알림·춤·응원은 시트의 자세 네 장을 순서대로 반복해 4초 VP9 알파 루프를 만든다. 출력은 모두 24fps이며 자세 갱신은 치타라 날개짓 8fps, 랩 4fps다. 응원·알림은 0.5초마다 최대 48px 위로 뛴다. [alignment.json](alignment.json)에 자세별 머리 양끝과 발바닥 좌표를 기록했다. 소품까지 포함한 시트 폭 대신 기본 우사기의 실제 머리 너비(271px)와 발바닥 기준선(462px)에 맞춰 각 자세를 배치한다. 승인한 원본 시트는 바꾸지 않는다. 공식 영상·음성은 사용하지 않는다. 앱에는 `assets/characters/usagi/`만 필요하며 이 원본 폴더는 자산 허용 목록으로 노출되지 않는다.
