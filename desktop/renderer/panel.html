치이카와 매니저 사용 설명

캐릭터와 함께 할 일, 일정, 연결한 앱의 알림과 AI 작업을 확인하는 개인 업무 도우미입니다.

처음 시작하는 순서

  1. AI 설정에서 사용할 AI를 선택하고 본인 계정으로 로그인하세요. AI 없이도 할 일과 캐릭터 기본 기능을 사용할 수 있습니다.
  2. 연결 관리에서 필요한 서비스만 연결하세요. 각자의 계정과 접근 권한을 사용하며 다른 사람의 연결 정보는 포함되어 있지 않습니다.
  3. 오늘 할 일에 오늘 처리할 일을 넣고, 끝낸 일은 완료로 표시하세요.

무엇을 할 수 있나요?

  • 홈·오늘 할 일·프로젝트: 진행 상태와 우선순위를 확인하고 할 일을 정리합니다.
  • 캘린더·알림: 연결한 일정과 Slack·메일·노션·GitHub의 지원되는 알림을 모아 봅니다. 연결하지 않은 앱의 내용은 볼 수 없습니다.
  • 채팅·작업 세션: 설정한 AI에 질문하고 작업 진행을 확인합니다. 외부 변경은 해당 기능의 확인 절차를 따릅니다.
  • 설정: 캐릭터와 말풍선 크기, 말풍선·알림 표시, 근무 시간과 날씨를 조절합니다.

내 노션에 채팅으로 작업 부탁하기

연결 관리 → 노션에서 본인의 내부 통합을 연결하고 콘텐츠 읽기·추가·업데이트 권한을 켭니다. 노션에서 사용할 상위 페이지의 ··· → 연결에 이 통합을 추가하세요. 허용된 페이지와 하위 페이지에서 작업하며 계정 전체에 자동 접근하지 않습니다.

채팅 예시: “노션에서 프로젝트 자료 찾아줘”, “이 페이지 요약해줘”, “이 페이지 아래에 회의록 만들어줘”, “이 페이지 끝에 다음 내용을 추가해줘”, “이 문단을 간단히 고쳐줘”. 변경은 대상과 본문이 표시된 카드의 실행 버튼을 누르면 저장됩니다. 문단 수정은 해당 문단의 글자 서식·링크를 일반 텍스트로 바꿉니다. 페이지 전체 삭제·이동, 데이터베이스 구조 편집은 지원하지 않습니다.

노션에 매일 업무기록 남기기

  1. 연결 관리 → 노션에서 본인이 만든 내부 통합을 연결합니다. 시크릿은 본인이 앱 입력칸에 직접 넣으세요.
  2. 노션 통합에 콘텐츠 읽기·추가 권한을 켜고, 저장할 일반 페이지의 ··· → 연결에서 통합을 추가합니다. 데이터베이스 직접 저장은 지원하지 않습니다.
  3. 앱의 노션 카드에서 상위 페이지 주소를 넣고 ‘이 페이지에 자동 기록 켜기’를 누릅니다. 기본값은 꺼짐입니다.
  4. 월~금 17시(한국 시간)에 날짜별 하위 페이지를 만듭니다. ‘오늘 기록 지금 실행’으로 시험할 수도 있습니다.

컴퓨터와 앱이 실행 중이며 인터넷·AI 로그인이 되어 있어야 합니다. 같은 날 17시 이후 앱을 켜면 확인하지만 지난 날짜를 자동으로 소급 작성하지는 않습니다. 업무 근거가 없으면 건너뜁니다.

정리 범위는 치이카와에 기록된 당일 할 일 변경과 작업 제목·실행 상태입니다. 전체 컴퓨터 활동이나 모든 대화 내용을 수집하지 않습니다. 기존 일지와 직접 쓴 내용은 덮어쓰지 않습니다. 노션 페이지를 공유한 사람도 기록을 볼 수 있으니 본인이 원하는 공유 범위의 페이지를 고르세요.

날씨와 화면 설정

처음 실행할 때 컴퓨터 시간대의 대표 도시로 날씨를 자동 조회합니다. 실제 위치를 측정하는 기능은 아닙니다. 설정 → 날씨에서 현재 지역을 확인하고 변경하세요. 모르는 시간대는 지역 검색이 필요하며, 지우기를 누르면 꺼집니다. 날씨는 인터넷이 필요하고 약 45분간 캐시합니다. 데이터: Open-Meteo (CC BY 4.0).

설정 → 이 앱에서 캐릭터와 말풍선 크기를 각각 50~150%로 조절할 수 있습니다. ‘크기 기본값으로’는 두 크기를 100%로 돌립니다. 말풍선 표시와 반투명 알림 표시는 각각 켜고 끌 수 있습니다.

문제가 생겼나요?

  • 연결 관리에서 오류와 로그인 상태를 먼저 확인하세요.
  • 노션 저장 실패: 페이지에 통합을 연결했는지, 콘텐츠 추가 권한이 있는지 확인하세요. 저장 결과가 불확실할 때는 중복 생성을 멈추고 상태에 안내합니다.
  • 설정 변경은 저장 결과를 확인하세요. 앱을 최신 버전으로 다시 실행해도 문제가 남으면 사용한 설정과 오류 화면을 알려 주세요.
