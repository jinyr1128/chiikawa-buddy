치이카와 매니저
매니저 꺼짐

개요

처음 사용하는 분을 위한 연결·설정 순서

앱의 연결 관리에서 필요한 서비스만 연결하세요. 배포 파일에는 제작자의 계정·회사 주소·개인 노트·연락처·토큰이 들어 있지 않습니다. 로그인과 권한 동의는 각 사용자가 직접 합니다.

1. AI와 바탕화면 채팅

  1. AI 설정에서 사용할 제공자를 고르고 로그인하거나 본인 API 키를 등록합니다.
  2. 바탕화면 캐릭터 위 채팅하기를 누르고 질문을 입력한 뒤 Enter로 보냅니다. Esc는 입력창을 닫습니다.
  3. 긴 답과 작업 확인 카드는 패널의 채팅에서 봅니다. 승인 전에는 노션 변경이 실행되지 않습니다.

2. 옵시디언

  1. Obsidian에서 사용할 볼트를 먼저 만듭니다. 볼트는 노트가 저장되는 실제 폴더입니다.
  2. 치이카와 연결 관리 → 옵시디언·업무기록 → 볼트 폴더 선택에서 그 폴더를 고릅니다. API 키나 별도 Obsidian 플러그인은 필요하지 않습니다.
  3. 업무기록 하위 폴더를 정합니다. 기본은 일일 업무기록입니다. 볼트 안에서 상대 경로로 입력합니다.
  4. 기존 양식을 쓰려면 템플릿의 볼트 내 경로에 템플릿/일일 업무기록.md처럼 입력하고 저장합니다. {{date}} 또는 {{date:YYYY-MM-DD}}는 기록 날짜로 바뀝니다. 기존 frontmatter와 GRAPH-LINKS 등은 양식에 그대로 두세요. 임의의 허브 파일을 자동 편집하지 않습니다.
  5. 필요한 노트 제목을 검색해서 할 일 연결을 누르면 해당 노트의 미완료 체크리스트가 보입니다. 날짜별 업무기록은 한국 날짜에 맞춰 오늘 노트로 전환합니다.
  6. 오늘 일지에 저장으로 메모를 넣거나 지금 업무 정리를 누릅니다. 저장 파일은 YYYY-MM-DD.md입니다. 오늘 파일이 없으면 첫 저장 때 만들어집니다. 어제 파일을 오늘 기록으로 덮어쓰지 않습니다.
  7. 원하면 17시 자동 정리 켜기를 누릅니다. 기본은 꺼짐입니다. 월~금 17시 한국 시간에 실행하며, 그날 늦게 앱을 켜도 확인합니다. 컴퓨터·앱·인터넷·AI 로그인이 필요합니다. 지난 날짜를 자동 소급 작성하지 않습니다.

자동 정리는 오늘 치이카와 할 일·작업 기록과 오늘 일지, 연결한 앱의 알림·일정 등을 근거로 합니다. 별도로 선택한 업무 폴더에서는 파일명과 수정시각만 읽습니다. 예정 일정이나 받은 요청을 완료 실적으로 바꾸지 않습니다. 자동 정리를 켜거나 직접 실행하면 근거 자료를 선택한 AI에 전달합니다. 기존 수기 본문은 보존하며 치이카와 자동 기록 영역만 다시 정리합니다. 중간에 날짜가 바뀌어도 정리를 시작한 날짜의 파일에 저장합니다.

3. 노션

  1. 노션 개발자 도구에서 신규 연결 → API 토큰 방식의 내부 연결을 만듭니다. 개인 워크스페이스 소유자 권한이 필요할 수 있습니다. 회사 정책으로 막히면 관리자에게 문의하세요. OAuth 방식은 이번 연결에 사용하지 않습니다.
  2. 콘텐츠 읽기·추가·업데이트, 댓글 읽기, 사용자 정보 읽기 권한을 설정합니다.
  3. 시크릿은 치이카와 연결 관리 → 노션 입력칸에 본인이 직접 붙이고 연결합니다. 채팅이나 공개 문서에 붙이지 마세요.
  4. 사용할 노션 상위 페이지에서 ··· → 연결 → 만든 연결 이름을 추가합니다. 허용한 페이지와 하위 페이지만 접근합니다.
  5. 채팅에서 “노션에서 접근 가능한 페이지 찾아줘”, “이 페이지 아래 회의록 만들어줘”처럼 요청합니다. 작성·수정은 확인 카드의 대상과 내용을 보고 실행합니다.
  6. 노션 자동 업무기록을 쓰려면 일반 상위 페이지 주소를 넣고 이 페이지에 자동 기록 켜기를 누릅니다. 옵시디언 자동 기록과 별개 설정이며 둘 다 켜면 각각 저장합니다. 노션은 같은 날짜의 기존 기록을 덮어쓰지 않습니다.

4. 캘린더와 Slack 자동 상태

  1. 연결 관리 → 캘린더에서 Mac 캘린더 또는 본인 iCal 주소를 연결합니다. iCal 비공개 주소도 인증정보이므로 공개하지 마세요.
  2. Slack 카드를 펼쳐 본인 워크스페이스의 앱과 사용자 토큰을 연결합니다. 기본 알림 권한 외에 자동 상태 기능은 users.profile:read, users.profile:write 사용자 권한이 필요합니다. 권한을 추가했다면 Slack 앱을 재설치해 새 토큰을 사용해야 할 수 있습니다.
  3. 캘린더 → Slack 상태 자동 변경에서 휴가 캘린더와 회의 캘린더를 선택합니다.
  4. Slack 상태 권한 확인 후 자동 상태를 켭니다. 연차·휴가가 회의보다 우선이며, 사용자가 직접 설정한 상태를 임의로 덮어쓰지 않습니다. 기본은 꺼짐입니다.

5. Microsoft Teams

이 연결은 회사·학교 Microsoft 365 계정용입니다. 회사 정책에 따라 관리자가 앱 등록이나 동의를 해야 합니다. 일반 개인 Microsoft 계정과 Teams 채널은 지원 범위에 포함되지 않습니다. 조회된 메시지의 멘션 포함 여부를 표시하고 선택한 대화방에 답장을 보낼 수 있습니다. 조회된 채팅 최대 20개에서 각 30개 메시지와 해당 날짜의 일정 최대 100개를 조회하므로 전체 대화 기록 수집을 보장하지 않습니다.

  1. Microsoft Entra 관리 센터의 앱 등록 → 새 등록에서 본인 조직용 앱을 만듭니다. 일반 사용자는 조직 관리자에게 이 단계를 요청할 수 있습니다.
  2. 인증 → 고급 설정 → 퍼블릭 클라이언트 흐름 허용을 켭니다. 이 방식에는 클라이언트 시크릿이나 리디렉션 주소를 입력하지 않습니다.
  3. Microsoft Graph 위임 권한에 User.Read, Chat.Read, ChatMessage.Send, Calendars.Read를 추가합니다. 앱은 로그인 유지에 offline_access도 요청합니다. 관리자 동의가 필요한 조직에서는 관리자가 승인합니다.
  4. 앱 개요의 애플리케이션(클라이언트) ID와 디렉터리(테넌트) ID를 치이카와 Teams 설정에 넣습니다.
  5. Teams 로그인 시작 → Microsoft 로그인 화면 열기를 누릅니다. 본인이 방금 만든 로그인 코드를 Microsoft 화면에 넣고 로그인·권한 내용을 확인합니다.
  6. 앱으로 돌아와 로그인 완료 확인 → 오늘 Teams 자료 확인을 누릅니다. 조직 정책으로 거부되면 관리자의 승인이 필요합니다.
  7. 메시지 옆 이 대화방에 답장 쓰기를 누르고 내용을 입력합니다. 받는 사람·내용 확인에서 전체 참여자와 본문을 확인한 뒤 확인한 내용 전송을 누릅니다. 선택한 방에 새 메시지를 보내며 원문을 인용한 스레드 답장은 아닙니다. AI가 자동으로 보내지 않습니다. 결과가 불명확하면 중복 전송하지 말고 Teams 앱에서 확인하세요.
  8. 로그인 토큰은 운영체제 보안 저장소로 암호화해 로컬에 저장합니다. Teams 연결 해제로 앱의 저장 토큰을 제거합니다. Microsoft 쪽 동의 자체를 철회하려면 조직 계정의 앱 권한 관리에서도 해제하세요.

구현 근거: Microsoft 디바이스 로그인, Teams 메시지 조회 권한, 메시지 전송.

6. 그룹웨어 화면 알림

회사별 그룹웨어는 공통 API가 없어 별도 Chrome 확장을 사용합니다. 로그인된 전용 탭에서 화면에 표시된 알림 제목만 읽습니다. 쿠키·비밀번호·첨부파일·문서 본문은 수집하지 않습니다. 제품별 화면 구조가 다르므로 모든 그룹웨어가 설정 없이 동작하는 것은 아닙니다.

  1. 릴리스의 chiikawa-groupware-extension.zip을 풀거나 저장소의 ops/groupware-extension 폴더를 사용합니다.
  2. Chrome 확장 관리에서 개발자 모드를 켜고 압축해제된 확장 프로그램 로드로 해당 폴더를 선택합니다. 아이폰 개발자 모드나 Xcode는 필요하지 않습니다.
  3. 치이카와에서 본인 그룹웨어 HTTPS 주소를 넣고 연결을 켭니다. 확장에 붙일 연결 키 복사를 누릅니다.
  4. 확장 옵션에 사이트 주소와 연결 키를 붙이고 해당 사이트 접근을 허용합니다. 연결 키를 다른 사람에게 공유하지 마세요.
  5. 기본 알림 선택자가 회사 제품과 맞지 않으면 관리자가 알림 제목에 해당하는 CSS 선택자를 지정해야 합니다. 전체 화면 본문을 선택하지 마세요.
  6. 본인이 그룹웨어에 로그인하고 알림 목록을 연 다음 확장 아이콘을 누릅니다. 전용 탭을 열어 두면 2분마다 보이는 목록을 확인합니다. 첫 확인은 기준 목록으로 저장하며 기존 알림을 모두 새 알림으로 울리지 않습니다.
  7. 새 항목은 연결 관리와 데스크톱 알림에 표시됩니다. 숨겨진 페이지·다른 탭·전체 과거 알림은 수집하지 않습니다. 중지는 확장 옵션의 자동 확인 중지와 앱의 연결 끄기를 사용합니다.

7. 날씨·화면

설정 → 날씨 지역·알림에서 도시를 검색한 뒤 결과를 선택하세요. 시간대 기본값은 실제 위치가 아니므로 한국 시간대에서도 서울 외 지역으로 바꿀 수 있습니다. 일반 설정 → 이 앱에서 캐릭터 크기와 말풍선 크기를 조절합니다.

연결이 안 될 때

  • 앱의 연결 카드에 표시된 오류를 먼저 확인하세요. 로그인 성공과 페이지·조직 권한 허용은 별개입니다.
  • 오늘 노트가 없다는 표시는 첫 저장 전 정상 상태입니다. 마지막 저장 날짜와 오늘 기준 날짜를 구분하세요.
  • 회사 정책으로 막힌 접근은 관리자에게 요청하세요. 권한 제한을 우회하지 않습니다.
  • 자동 정리의 실제 무인 실행과 Teams·그룹웨어 실계정 연결은 각 환경에서 확인해야 합니다. 모의 검사 통과가 사용자의 계정 연결 완료를 뜻하지 않습니다.
