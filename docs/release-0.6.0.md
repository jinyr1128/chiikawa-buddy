# v0.6.0 · 업무 연결과 오늘 기록

각 사용자가 본인 계정과 폴더를 연결해 쓰는 공개판입니다. 제작자의 개인 노트, 인증정보, 회사 주소와 개인 설정은 배포하지 않습니다.

- 옵시디언 볼트·템플릿·업무 폴더 선택, 오늘 메모와 평일 17시 업무 정리. 날짜가 바뀌면 오늘 일지로 전환하고 기존 수기 내용은 보존합니다.
- 노션 조회·확인 후 작성, 날짜별 자동 업무기록, 바탕화면 채팅, 날씨 지역 설정과 캐릭터별 날씨 문구를 포함합니다.
- 선택한 휴가·회의 캘린더에 따른 Slack 상태 변경. 기본 꺼짐이며 직접 설정한 상태를 유지합니다.
- 회사·학교 Teams 로그인, 채팅·멘션 포함 메시지·일정 조회, 받는 사람과 내용을 확인한 뒤 선택한 대화방에 메시지 전송. 일반 개인 계정·Teams 채널·인용 스레드 답장은 제외합니다.
- 선택 사항인 Chrome 그룹웨어 알림 확장. 본인 회사 주소와 화면 구조에 맞는 설정이 필요합니다.
- 앱의 **설명보기**와 [연결·설정 안내](https://github.com/jinyr1128/chiikawa-manager/blob/main/docs/연결-설정.md)에 처음부터 설정하는 순서를 담았습니다.

Teams는 Microsoft Entra 앱 등록과 조직의 권한 동의가 필요할 수 있습니다. 각 연결은 기본 미연결이며 자동 기록은 직접 켜야 합니다. PC·앱·인터넷·AI 로그인이 유지되어야 자동 정리가 실행됩니다.

Mac은 `chiikawa-app-arm64.zip`, Windows는 별도 `v0.6.0-windows` 릴리스의 설치 파일을 사용합니다. 기존 앱을 완전히 종료한 뒤 교체하세요. 계정과 노트 설정을 삭제하지 마세요. 그룹웨어를 사용할 분만 `chiikawa-groupware-extension.zip`을 추가로 받으세요.

검증: agent 1,102개 통과(8개 제외), desktop 747개 통과. 날짜 전환·기존 노트 보존·Teams 전송 확인/중복 방지·그룹웨어 접근 검사를 포함합니다. Mac 설정·연결 화면을 확인했습니다. 실제 Teams/회사 그룹웨어 연결과 전송은 각 조직 계정에서 별도 확인이 필요합니다.
