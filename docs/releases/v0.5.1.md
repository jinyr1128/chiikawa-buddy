# 치이카와 매니저 v0.5.1

설정 → 이 앱에서 캐릭터 크기와 안내 말풍선 크기를 각각 50~150%로 조절할 수 있습니다. 화면의 ‘말풍선 가리기’ 또는 설정의 ‘말풍선 표시’로 말풍선을 숨기고 다시 켤 수 있습니다. 설정은 재실행해도 유지됩니다.

## 이미 설치한 분: 계정 연결을 유지하며 업데이트

앱을 삭제하거나 ‘연결 해제’를 누를 필요가 없습니다. 기존 계정 연결, 설정, 캐릭터, 기록은 앱과 별도로 보관됩니다.

- Mac: 치이카와 매니저를 종료하고 아래 `chiikawa-manager-arm64.zip`을 받아 압축을 풉니다. 새 앱을 기존 설치 위치(보통 응용 프로그램)에 옮기고 ‘대치’를 선택한 다음 실행하세요. 데이터 폴더는 삭제하지 마세요.
- 저장소로 설치한 Mac: 저장소 폴더에서 `./ops/update.sh`를 실행하세요. 앱만 교체하고 초기 설정·캐릭터·연동을 다시 설치하지 않습니다.
- Windows: Windows용 v0.5.1 릴리스의 Setup.exe를 받아 기존 앱 종료 후 실행하세요. 휴대용 사용자는 새 zip을 풀어 실행하세요. Mac zip은 Windows용이 아닙니다.

연결 정보는 같은 컴퓨터·같은 OS 사용자 계정에서 유지됩니다. 서비스 자체의 로그인 만료나 권한 철회는 재로그인이 필요할 수 있습니다. 개인용으로 수정한 앱은 공개판으로 덮어쓰지 말고 해당 개인용 코드를 업데이트하세요.

설정에 ‘업데이트 다운로드 · 방법 보기’ 버튼을 추가했고, 공개판 새 버전 알림이 공개 저장소의 Mac zip도 찾도록 고쳤습니다. 예전 버전에서 알림이 뜨지 않으면 위 방법으로 한 번 업데이트해 주세요.
