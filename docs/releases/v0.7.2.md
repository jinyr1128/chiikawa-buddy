연결한 캘린더의 오늘 회의가 **오늘 할 일**에 올라옵니다. 매니저를 켜 두면 예정 종료 시각이 지난 회의에는 자동으로 완료 표시가 붙습니다. 회의 화면을 따로 열 필요가 없습니다.

- 종료 시각을 연장하면 바뀐 시각을 따릅니다. 회의록 작성이나 자료 공유 등 별도로 등록한 후속 할 일은 직접 완료할 수 있습니다.
- 참석하지 않은 회의는 **할 일 → 최근 완료 → 되돌리기**를 누르세요. 해당 회차는 다시 자동으로 체크하지 않습니다.
- 사용하려면 **연결 관리 → 캘린더**에서 본인의 캘린더를 연결하세요. 이미 연결했다면 바로 사용할 수 있습니다.

**업데이트 방법** · v0.7.1 사용자는 **설정 → 이 앱 → 지금 업데이트 확인**을 누른 뒤 **지금 업데이트 → 설치하고 다시 시작**을 선택하세요. 자동 알림을 켜 두면 앱이 하루 한 번 새 버전을 확인합니다. 이전 버전과 Windows 휴대용 사용자는 운영체제에 맞는 최신 파일을 내려받아 주세요.
