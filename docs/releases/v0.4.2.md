# 치이카와 매니저 v0.4.2

애플 실리콘 맥(M1 이상)용. 비공개 저장소에 초대받은 GitHub 계정이 필요합니다.

## AI에게 설치 맡기기

로컬 파일과 터미널을 사용할 수 있는 Claude Code 또는 Codex에게 다음 문장을 전달하세요.

> https://github.com/jinyr1128/chiikawa-buddy 를 내 맥에 설치해줘. AGENTS.md를 읽고 ops/setup-mac.sh로 최신 릴리스를 설치하고 앱 실행과 캐릭터를 확인해줘. GitHub 로그인과 개인 서비스 연결은 내가 직접 할게.

직접 설치: `gh repo clone jinyr1128/chiikawa-buddy` 후 저장소에서 `./ops/setup-mac.sh`.
업데이트: 저장소에서 `git pull --ff-only && ./ops/setup-mac.sh`.

## 변경

- 집중 모드에 독서·공부 원본 장면 적용. 합성 장식과 10초마다 바뀌는 장면 제거. 적합한 장면이 없는 3명은 기존 대기 그림 유지.
- 오늘 할 일에서 연결된 캘린더의 하루 전체 일정과 노션의 미완료 항목 조회. 노션은 통합에 공유한 페이지 범위만 지원.
- Codex의 기존 대화 여러 개를 이어 쓸 때 작업 세션 충돌 수정.
- 앱 zip과 캐릭터 11명 묶음, SHA-256 검증을 포함한 설치 경로 제공.

## 연결과 확인 범위

Codex CLI 실제 실행·완료 알림, 홈 사용량 표시, 집중 원본 그림, 오늘 일정 영역을 확인했습니다. Claude CLI는 개인 로그인 후 확인해야 합니다. 노션·네이버 캘린더도 각자의 연결이 필요하며 로그인 완료가 배포 파일에 포함되지 않습니다. 개인 설정, 인증 정보, 메일, 일정, 대화는 배포하지 않습니다.
