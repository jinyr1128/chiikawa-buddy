# 치이카와 매니저 v0.5.2

- 캐릭터 옆에 **말풍선 가리기 ↔ 보이기**, **알림 가리기 ↔ 보이기** 버튼이 항상 남습니다.
- 대화·작업 상태 말풍선과 위쪽 반투명 알림을 각각 숨기고 다시 켤 수 있습니다. 숨겨도 알림 수신·홈 알림함은 유지됩니다.
- 설정 → 이 앱에서 두 표시 설정과 캐릭터/말풍선 크기(50~150%)를 조절합니다.
- GitHub 첫 화면에 다운로드, 연결 유지 업데이트, 크기·표시 설정 방법을 추가했습니다.

## 기존 사용자 업데이트

연결 해제·데이터 삭제 없이 앱만 교체하세요. Mac은 앱 종료 → 아래 zip 다운로드·압축 풀기 → 기존 앱 위치에 대치 → 실행. 저장소로 설치했다면 `./ops/update.sh`를 사용하세요. Windows는 Windows용 v0.5.2 릴리스의 Setup.exe를 실행하세요. 같은 컴퓨터·같은 사용자 계정의 연결 정보·설정·캐릭터·기록은 그대로 유지됩니다. 서비스 자체의 로그인 만료는 재인증이 필요할 수 있습니다.
