# 치이카와 매니저 v0.5.3

- 바탕화면 캐릭터 위의 **채팅하기** 버튼으로 설정 창 없이 바로 입력할 수 있습니다. 버튼으로 연 입력창은 마우스를 옮겨도 유지되며, 말풍선 숨김과 별도로 표시됩니다.
- **설정 → 날씨 지역·알림**에서 도시를 검색하고 결과를 선택하면 저장됩니다. 컴퓨터 시간대의 기본 도시는 실제 위치가 아니므로 원하는 지역으로 바꿔 주세요.
- 모몽가의 날씨 안내를 상황에 맞게 다듬었습니다. 각 기본 캐릭터는 자신의 말투로 기온과 강수 정보를 전달합니다.
- **설명보기** 탭에서 기능과 연결·설정 방법을 확인할 수 있습니다. 크기 조절 설정의 배치도 개선했습니다.
- 본인의 노션 내부 연결(API 토큰)을 연결하면 접근을 허용한 페이지를 검색·요약하고, 새 페이지 만들기·본문 추가·문단 수정·제목 변경을 요청할 수 있습니다. 작성·수정은 확인 카드에서 승인해야 실행됩니다. 콘텐츠 읽기·추가·업데이트 권한과 페이지 접근 허용이 필요합니다.
- 노션 **17시 자동 업무기록**을 추가했습니다. 기본 꺼짐이며, 저장할 일반 상위 페이지를 지정하고 켜야 합니다. 월~금 17시 한국 시간, 앱과 컴퓨터가 켜져 있을 때 치이카와에 남은 당일 업무 근거를 정리합니다. 전체 컴퓨터 활동을 수집하거나 기존 일지를 덮어쓰지 않습니다.

## 연결과 사용 범위

각 사용자가 본인 노션을 연결해야 합니다. 내부 연결을 만들 권한이 없는 워크스페이스는 소유자에게 문의해야 합니다. OAuth 로그인 연결은 이번 버전에 포함되지 않습니다. 노션 페이지 전체 삭제·이동과 데이터베이스 구조 편집은 지원하지 않으며, 문단 수정은 해당 문단을 일반 텍스트로 바꿉니다.

## 업데이트

앱을 완전히 종료한 다음 기존 앱 파일만 교체하세요. 같은 사용자 계정의 연결 정보·캐릭터·기록·설정은 유지됩니다. 개인 수정 앱은 공개 앱으로 덮어쓰지 마세요. macOS 설치 파일은 Apple Silicon용이며 ad-hoc 서명입니다. Windows 설치 파일은 별도의 v0.5.3-windows 릴리스로 제공됩니다.
