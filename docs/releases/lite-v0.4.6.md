# 치이카와 매니저 v0.4.6 (공유판)

치이카와 친구들이 바탕화면에서 AI(Claude Code·Codex·Hermes)가 일하는 모습을 보여 주고, 메일·Slack·캘린더·노션·GitHub 알림을 모아 주는 애플 실리콘 맥용 앱이에요.

**설치는 꼭 AI로**: Claude Code나 Codex에게 이 저장소 주소를 주고 「이거 내 맥에 설치해줘. AGENTS.md 대로 해줘」라고 말하세요. GitHub 로그인은 필요 없어요.

- 기본 캐릭터 8명(치이카와·하치와레·우사기·모몽가·쿠리만쥬·랏코·카니·시사), 기능은 모두 들어 있어요.
- 캐릭터마다 대표 색 말풍선, 작업 중 움짤 3개 이상, AI 사용량 표시, 메뉴 막대 캐릭터 얼굴.

비상업 팬 프로젝트예요. 치이카와 캐릭터의 권리는 원작자(나가노)와 권리사에 있어요.
